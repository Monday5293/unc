# 跑团角色卡平台 - 产品需求文档 (PRD)

## 1. 产品概述

本项目是一套面向 TRPG（桌上角色扮演游戏）跑团玩家的"小程序 + 网页"双端工具集。
- **小程序端**：展示不同跑团规则（克苏鲁的呼唤 COC、龙与地下城 D&D、匕首之心 Daggerheart）的角色卡数据，角色卡以 JSON 形式存储，在类可视化表单的卡片中呈现，支持点开放大查看，并设有"卡面展示页"与"个人中心页"两个核心页面。
- **网页端**：基于开源库 `form-create-designer` 搭建可视化表单设计器，预制 COC 与 DND 表单模板，便于玩家/主持人快速生成、编辑与导出角色卡 JSON 数据。

目标用户为 TRPG 跑团玩家、KP/DM 主持人，市场价值在于打通"表单设计 → 数据生成 → 卡面展示"的跑团数字化工作流。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 跑团玩家 | 本地账号 / 免登录浏览 | 浏览、放大查看角色卡，管理个人收藏 |
| KP/DM 主持人 | 本地账号 | 在网页端设计/编辑表单、导出 JSON、推送到小程序展示 |

### 2.2 功能模块

**小程序端（移动端模拟）**
1. **卡面展示页（首页）**：规则切换 Tab（COC / DND / Daggerheart）、角色卡瀑布流、点击放大查看、搜索筛选
2. **个人中心页**：用户信息、我的角色卡、收藏夹、关于

**网页端（桌面端）**
1. **表单设计器**：基于 form-create-designer 的拖拽式可视化表单设计
2. **预制模板**：COC 角色卡模板、DND 5e 角色卡模板
3. **数据预览/导出**：实时表单 JSON 预览、导出为角色卡 JSON

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 小程序-卡面展示页 | 规则切换 Tab | 顶部 Tab 切换 COC / DND / Daggerheart，切换后瀑布流刷新 |
| 小程序-卡面展示页 | 角色卡瀑布流 | 卡片网格展示角色头像、名称、关键属性，悬浮微动效 |
| 小程序-卡面展示页 | 卡片放大查看 | 点击卡片弹出全屏模态，展示完整可视化表单与所有属性 |
| 小程序-卡面展示页 | 搜索筛选 | 按名称/职业/等级筛选 |
| 小程序-个人中心页 | 用户信息卡 | 头像、昵称、统计数据（拥有卡数、收藏数） |
| 小程序-个人中心页 | 我的角色卡 | 列表式展示个人创建/收藏的角色卡 |
| 小程序-个人中心页 | 关于 | 版本信息、开源致谢 |
| 网页-表单设计器 | 拖拽设计面板 | 左侧组件库、中间画布、右侧属性配置 |
| 网页-表单设计器 | 模板加载按钮 | 一键加载 COC / DND 预制模板 |
| 网页-表单设计器 | JSON 预览/导出 | 实时显示表单 schema JSON 与可下载 |

## 3. 核心流程

**小程序端查看角色卡流程**：用户进入小程序 → 卡面展示页加载默认规则角色卡列表 → 通过 Tab 切换规则 → 点击某张卡片 → 全屏放大查看完整属性表单 → 关闭返回列表。

**网页端设计表单流程**：KP 打开网页设计器 → 选择"加载 COC 模板"或"加载 DND 模板" → 在画布中拖拽调整字段 → 右侧配置字段属性 → 预览 JSON → 导出角色卡 JSON 文件 → 可放入小程序数据目录展示。

## 4. 用户界面设计

### 4.1 设计风格

整体采用 **"暗黑奇幻 + 古卷羊皮纸"** 的混合美学：
- **小程序端**：移动端深色为主基调，搭配规则特色强调色（COC 暗绿腐化、DND 龙金红、Daggerheart 月白银），仿羊皮纸纹理卡片背景
- **网页端**：桌面端工具型布局，深色侧栏 + 浅色画布工作区，专业设计器风格
- 主色：墨黑 `#0F0E0C`、羊皮纸 `#E8DCC4`
- COC 强调色：腐化绿 `#3B6B4A`
- DND 强调色：龙焰金 `#C8A046`
- Daggerheart 强调色：月银 `#9BA8B5`
- 字体：标题使用 `Cinzel`（古典衬线），正文使用 `Noto Sans SC`
- 按钮风格：圆角矩形带微浮雕阴影，hover 时金色描边
- 布局：小程序为底部 Tab 导航 + 卡片网格；网页为三栏工作台布局

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 小程序-卡面展示页 | 顶栏 | 规则 Logo + Tab 切换，墨黑底 + 强调色下划线 |
| 小程序-卡面展示页 | 瀑布流 | 2 列卡片，羊皮纸纹理背景，圆角 12px |
| 小程序-卡面展示页 | 放大模态 | 全屏深色遮罩，居中卡片，可滑动查看完整属性 |
| 小程序-个人中心页 | 用户信息卡 | 圆形头像 + 昵称 + 统计数字 |
| 小程序-个人中心页 | 我的卡片列表 | 单列卡片行，左侧缩略图 + 右侧名称职业 |
| 网页-表单设计器 | 左侧组件库 | 折叠分组列表，深色背景 |
| 网页-表单设计器 | 中间画布 | 浅色画布，表单实时渲染 |
| 网页-表单设计器 | 右侧属性面板 | 字段配置表单，深色背景 |
| 网页-表单设计器 | 顶部工具栏 | 模板加载按钮 + JSON 预览 + 导出按钮 |

### 4.3 响应式

- 网页端采用桌面优先设计，最小支持 1024px 宽度，三栏工作台布局
- 小程序端采用移动端优先设计，模拟 375px 宽度手机视口，底部 Tab 导航

### 4.4 3D 场景说明

本项目不含 3D 场景。
